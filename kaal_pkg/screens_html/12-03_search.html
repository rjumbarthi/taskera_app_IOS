How to read this file. The HTML below is the prototype's raw markup for screen p-search. It renders the screen's initial state at the design viewport (390 × 844).

The PNG is the ground truth for visual state. Many screens depend on JS to populate content, expand groups, apply filters, or scroll — this static HTML cannot reproduce those.

When implementing in Compose, use the PNG for what the user sees, this HTML for the markup hierarchy and inline styles, and shared/shared.css for class-level rules.
